# Muskan — AI Health Assistant

This is a responsive HD-style web app prototype based on the supplied Muskan design.

Included:
- Muskan branded home dashboard
- AI Doctor text chat
- Browser voice input and text-to-speech
- Multiple language selector
- Medicine information screen
- Diet & fitness
- Pregnancy & child care
- Health report upload UI
- Emergency guidance
- Responsive mobile-first interface

IMPORTANT:
This package is a frontend prototype. The AI chat currently uses safe demo replies.
For a production AI medical assistant, connect the chat to a secure backend/AI provider,
add authentication, privacy controls, medical-content review, audit logs, and appropriate
clinical safety/emergency handling. Do not expose API keys in the browser.
